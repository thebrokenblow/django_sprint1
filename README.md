# Blogicum - Социальная сеть для публикации личных дневников

## Описание проекта
Blogicum — это социальная сеть, где пользователи могут публиковать личные дневники. Каждый пользователь может создать свою страницу, публиковать посты с указанием категории и локации, читать и комментировать посты других пользователей.

## Функциональность
- Публикация личных дневников (постов)
- Указание категорий и локаций для постов
- Просмотр постов по категориям
- Чтение и комментирование чужих постов
- Статические страницы (О проекте, Наши правила)

## Технологии
- Python 3.11+
- Django 3.2.16
- Bootstrap 5

## Установка и запуск

### 1. Клонирование и настройка окружения
```bash
git https://github.com/thebrokenblow/django_sprint1.git
cd django_sprint1

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Для Windows:
venv\Scripts\activate
# Для Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

### 2. Настройка проекта
cd blogicum
python manage.py migrate

### 3. Запуск сервера
python manage.py runserver

После запуска сервера проект будет доступен по адресу: http://127.0.0.1:8000/

## Тестовые данные

В приложении blog используются фиктивные данные из словаря posts, содержащего три поста:

1. 30 сентября 1659 года - Категория: travel
2. 1 октября 1659 года - Категория: not-my-day
3. 25 октября 1659 года - Категория: not-my-day

Посты отсортированы в обратном хронологическом порядке (от новых к старым).
