# Blogicum - Социальная сеть для публикации личных дневников

## Описание проекта
Blogicum — это социальная сеть, где пользователи могут публиковать личные дневники. 
Каждый пользователь может создать свою страницу, публиковать посты с указанием 
категории и локации, читать и комментировать посты других пользователей.

## Функциональность
- Публикация личных дневников (постов)
- Указание категорий и локаций для постов
- Просмотр постов по категориям
- Чтение и комментирование чужих постов
- Статические страницы (О проекте, Наши правила)

## Технологии
- Python 3.11+
- Django 3.2.16
- Bootstrap 5
- SQLite (для разработки)

## Установка и запуск

### 1. Клонирование и настройка окружения
git clone <ваш-репозиторий>
cd django_sprint1

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Для Windows:
venv\Scripts\activate
# Для Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

### 2. Настройка проекта
cd blogicum
python manage.py migrate
python manage.py createsuperuser  # опционально

### 3. Запуск сервера
python manage.py runserver

После запуска сервера проект будет доступен по адресу: http://127.0.0.1:8000/

## Маршруты (URL)

Адрес                      Приложение  Функция         Описание
/                          blog        index           Главная страница с лентой записей
/posts/<int:post_id>/      blog        post_detail     Детальная страница поста
/category/<slug:...>/      blog        category_posts  Страница категории
/pages/about/              pages       about           Страница "О проекте"
/pages/rules/              pages       rules           Страница "Наши правила"

## Тестовые данные

В приложении blog используются фиктивные данные из словаря posts, содержащего три поста:

1. 30 сентября 1659 года - Категория: travel
2. 1 октября 1659 года - Категория: not-my-day
3. 25 октября 1659 года - Категория: not-my-day

Посты отсортированы в обратном хронологическом порядке (от новых к старым).

## Особенности реализации

### Шаблоны
- Используется наследование шаблонов (базовый шаблон base.html)
- Частичные шаблоны для header и footer
- Django template language для динамического контента
- Bootstrap для стилизации

### Безопасность
- Проверка существования постов перед отображением
- Обработка несуществующих ID через Http404
- Экранирование пользовательского ввода

### Производительность
- Использование словаря для быстрого поиска постов по ID
- Оптимизированная сортировка по датам
- Минимальное количество запросов к данным
